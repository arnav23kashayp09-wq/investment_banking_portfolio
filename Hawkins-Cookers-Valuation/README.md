# Hawkins Cookers Ltd. — Financial Modeling & Valuation

## Project Overview

Built an integrated financial analysis and valuation model for Hawkins Cookers Ltd. covering historical financial statements, forecasting, financial ratio analysis, ROIC, WACC, DCF valuation and comparable company analysis.

## Analysis Performed

- Historical Income Statement, Balance Sheet and Cash Flow Analysis
- Common-Size Financial Statements
- Financial Ratio Analysis
- Revenue, EBITDA and Net Profit Forecasting
- ROIC and Reinvestment Analysis
- WACC and Beta Analysis
- FCFF-Based DCF Valuation
- Comparable Company Valuation
- Regression Beta Analysis
